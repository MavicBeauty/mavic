# Brand — Mavic Beauty & Nails

_Status: documented from existing implementation (not generated by brand-design)_

This project already has a live, consistent brand applied across the entire production site — this file just records it so tooling doesn't re-prompt for palette selection.

## Palette

Defined in `tailwind.config.ts` under the `mavic` color namespace:

| Token | Hex | Use |
|---|---|---|
| `mavic-pink` | `#F8B4C8` | Primary accent — buttons, headers, active states |
| `mavic-pink-light` | `#FDE8EF` | Light tint backgrounds, hover fills |
| `mavic-gold` | `#C9A84C` | Secondary accent — paired with pink in gradients, PDF/export actions |
| `mavic-beige` | `#F5EDD6` | Page background (`bg-mavic-beige`) |
| `mavic-beige-dark` | `#E8D5B0` | Deeper beige accents |
| `mavic-black` | `#1A1A1A` | Primary text color |

Common gradient: `bg-gradient-to-r from-mavic-pink to-mavic-gold` — used on page headers and primary CTAs throughout `/admin`.

Semantic colors follow plain Tailwind (not custom tokens): `green-*` for success/signed states, `red-*` for errors/destructive actions, `amber-*`/`orange-*` for warnings and pending states, `gray-*` for neutral text/borders.

## Typography

- **Font:** Poppins, loaded via `next/font/google` in `app/layout.tsx`, exposed as `--font-poppins` / `font-poppins` and applied globally on `<body>`.
- No secondary/mono font in use.

## Voice

- Admin/internal tools are written in plain, warm Spanish — the audience includes non-technical staff (e.g. the co-owner running `/admin`), so copy avoids jargon and explains things in everyday terms.
- Public-facing site copy (client-facing pages) uses Spanish/Catalan per `next-intl` locale routing.

## Component conventions

- No component library (no shadcn/ui) — plain Tailwind utility classes, hand-rolled modals (`fixed inset-0 bg-black/50 flex items-center justify-center z-50 p-4` + `bg-white rounded-xl shadow-2xl p-6`).
- Icons are inline SVG (`stroke="currentColor"`, `strokeWidth={2}`, `viewBox="0 0 24 24"`) — no icon package.
- No animation library — CSS transitions only (`transition`, `duration-150`, opacity fades).
